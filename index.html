Apresentação do projeto

Este software foi desenvolvido originalmente para uma atividade de Programação com Interfaces Gráficas usando Python e TKinter, proposta na graduação.

Para permitir a visualização e demonstração diretamente pelo navegador, foi criada esta versão Web. Porém o código da versão original pode ser acessado através do GitHub e executado diretamente, sugiro, no VSCode.
